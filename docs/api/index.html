REST API for managing data connections and connection types.

Authentication

All endpoints except /health require a bearer token. All endpoints except /health and /audit/data-connection-types additionally require the x-tenant-id header.

A missing or invalid token returns 401, and a token that lacks permission for the requested operation returns 403. A missing or empty x-tenant-id header is a request validation failure and returns 400, not 401; a well-formed header naming a tenant you cannot access returns 403.

1. Obtain a token

For your own user:

export user_token=$(oc whoami -t)

For a ServiceAccount, bind the audience the service expects:

export user_token=$(oc create token <sa-name> -n <namespace> \
  --audience="$(oc get authentication cluster -o jsonpath='{.spec.serviceAccountIssuer}')" \
  --duration=1h)

The token audience must match the DataConnectService CR's configured spec.tokenReviewAudiences; a mismatch returns 401 unauthenticated. The list is empty by default, in which case the cluster API server's own audience applies.

2. Send the request

export TENANT_NAMESPACE=dch-example

curl -H "Authorization: Bearer $user_token" \
     -H "x-tenant-id: $TENANT_NAMESPACE" \
     https://dch-rest-dch-services.apps.example.com/api/v1alpha1/data/connections

Download binary data from a connection

Streams binary data (files, objects) from a data connection. The file path is connector-specific: for S3 it is an object key within the configured bucket, for URI connectors it is a relative URL path joined to the base URI. Only connectors that support binary reads (currently S3 and URI) will return data; all others respond with 501.

connection-types

A connection type defines a schema for a data connection. A connection type must be created before creating a connection of that type. Connection types are typically created by the Data Connect Hub operator, but you can also create your own custom connection types. Connection types created by the operator are known as global connection types and are accessible by all tenants. Connection types created by a tenant are only accessible by that tenant.

List connection types

Returns all connection types that are accessible to the tenant. This includes global connection types created by the operator and any custom connection types created by the tenant.
